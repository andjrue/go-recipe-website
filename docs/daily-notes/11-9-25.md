### Design Decisions
Each layer has a centralized creation method that can be used for dependency injection elsewhere. This simplifies dev a ton, and makes it easy to map out the workflow. The application directory will house all of our dependencies and makes setting up main easy. 

The repository pattern abstracts each layer and houses logic relevant to that layer and that layer only. The handler doesn't need to know how the service layer works, it just needs to interact with it. I don't plan on doing this, and I really only set it up this way to show off in the project, but it is a proven pattern that is making my life a lot easier.
