# go-recipe-website

## Overview
Welcome to the Go Recipe Website! Thanks for stopping by. 

This project was set up in order to centralize my families recipes. I find that food is how we've always connected, and now that we all live apart, its difficult for us to share with one another.

If you have any questions about the website, or are very impressed by it, feel free to shoot me an email. It should be on the resume HR sent over. 

## Why I Chose Go
Go is a great language with a robust standard library. I was originally going to write this in Java, but a few hours in I realized I was really learning Springboot and the hard decisions were abstracted away. That's great for an enterprise level application, but I wanted to sit down and write my own code. 

I also find that Go is more difficult to vibe code than other languages. That means I have to sit down and write it myself and not argue with an LLM about why its implementation is incorrect. This has been pretty refreshing, honestly. It's easy to get caught in a prompt cycle, but Go has largely prevented that from happening. Every line of backend code was written by me, usually after an hour or two of reading docs.
